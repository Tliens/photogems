# PhotoGems · 兰台

A hand-curated personal photo gallery — browse & download for free.

**Live: https://photogems.kuige.me/**

Static, zero-dependency single-page gallery. Photos live in `img/<collection>/`, the index in `data.js` — both are generated by a local build script and published on every sync.

Codename **兰台 (Lantai)** — the imperial archive of the Han dynasty, now holding light and shadow.

Part of the [kuige.me](https://kuige.me/) toolkit.
